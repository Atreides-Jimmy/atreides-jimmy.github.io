## 1. 产品概述

Atreides-Jimmy 的 GitHub 个人主页——一个以"沙丘"（Dune）美学为灵感的个人品牌展示站。以沙漠之城的庄严与科幻优雅为基调，呈现开发者身份、诗歌品味与项目作品。
- 目标：打造一个令人印象深刻的个人主页，体现独特的审美品味与技术实力
- 目标用户：访问者（潜在雇主、合作者、技术社区成员）

## 2. 核心功能

### 2.1 功能模块

1. **主页**：名称展示、诗歌框、导航入口、语言切换
2. **项目页**：GitHub 项目展示
3. **联系页**：联系方式与社交链接

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页 | 英雄区 | 大号名称展示，带入场动画 |
| 主页 | 诗歌框 | 精致边框内展示一首诗，内容可自定义 |
| 主页 | 导航区 | 联系、我的项目、关于我等入口卡片 |
| 主页 | 语言切换 | 中英文一键切换，影响全站文案 |
| 项目页 | 项目列表 | 从 GitHub 仓库获取并展示项目卡片 |
| 项目页 | 项目详情 | 项目描述、技术栈、链接 |
| 联系页 | 联系方式 | 邮箱、GitHub、社交媒体链接 |
| 联系页 | 留言区 | 简单的留言表单（静态展示） |

## 3. 核心流程

用户访问主页 → 看到名称与诗歌 → 通过导航进入项目页或联系页 → 切换语言查看不同语言版本

## 4. 用户界面设计

### 4.1 设计风格

- **主题**：沙丘美学（Desert Noir）—— 深色底色 + 沙金点缀 + 沙漠纹理
- **主色**：深炭黑 `#0D0D0D`，沙金色 `#C9A96E`，暖沙色 `#D4B896`
- **辅助色**：暮光紫 `#6B5B8D`，星光白 `#F0EDE6`
- **字体**：展示字体使用 Cormorant Garamond（优雅衬线体），正文使用 DM Sans（现代无衬线）
- **布局**：居中对称布局，大量留白，卡片式导航入口
- **动画**：入场渐显动画、悬浮微交互、沙粒纹理背景
- **边框风格**：双线金边装饰框（用于诗歌框），呼应沙丘中的贵族纹章感

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主页 | 英雄区 | 居中大号衬线字体名称，渐显动画，沙粒纹理背景 |
| 主页 | 诗歌框 | 双线金边装饰框，衬线体诗歌文本，淡雅背景 |
| 主页 | 导航区 | 水平排列的图标+文字卡片，悬浮发光效果 |
| 主页 | 语言切换 | 右上角简洁切换按钮，中/EN 标签 |
| 项目页 | 项目列表 | 网格布局项目卡片，悬浮提升效果 |
| 联系页 | 联系方式 | 图标+文字列表，社交链接 |

### 4.3 响应式设计

- 桌面优先设计
- 移动端自适应：导航卡片改为垂直排列，诗歌框宽度自适应
- 触摸优化：增大点击区域

### 4.4 视觉细节

- 背景添加细微噪点纹理，营造沙漠质感
- 诗歌框使用装饰性角标（corner ornaments）
- 导航卡片悬浮时出现沙金色光晕
- 页面切换使用淡入淡出过渡
